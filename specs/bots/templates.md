# Bot templates

- A template is a reusable, named bundle: machine selection (`bots/sandbox-customization.md`), role, instructions, plus optional starter triggers (message + schedule shapes only; webhook triggers are not templated).
- Templates are created from scratch or "Save as template…" from any bot's detail menu; managed in a **Templates** area with add/edit/delete behind confirm dialogs.
- "New bot" offers a template picker: choosing one pre-fills the create dialog, which stays fully editable before submitting; instantiating copies values into fresh rows — templates and bots stay independent afterwards.
- Deleting a template never touches bots created from it; referencing a deleted machine or role shows an inline warning in the editor.
