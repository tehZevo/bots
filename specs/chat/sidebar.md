# Chat sidebar

- Clicking/tapping a bot card opens that bot's chat in a closeable sidebar pinned to the right edge of the window; the cards behind stay visible.
- The sidebar shows that bot's conversation and input per `messages.md` (history, optimistic send, streaming replies, markdown, tool/thinking sections).
- The sidebar closes via its close button, Escape, or clicking outside; closing changes nothing about the bot.
- A settings (gear) icon in the sidebar header opens that bot's settings modal (`../bots/detail.md`): name, instructions, role, triggers, logs and actions.
- Only one chat sidebar is open at a time; opening another bot's card switches the sidebar to that bot in place.
- On phones the sidebar spans the full screen like the detail modal.
