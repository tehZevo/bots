# Notification sounds

- Playing a sound on new notifications is a Settings toggle (default off) with a `Preview` button; it applies while any app page is open, respecting the in-app list (`notifications/in-app.md`).
- Each bot may set its own sound in detail General: none / default chime / one of a small built-in library (~6 short synth sounds); unset means the global default.
- Sounds are bundled static assets — no uploads; playback respects browser autoplay rules and needs no extra permission beyond an existing user interaction on the page.
