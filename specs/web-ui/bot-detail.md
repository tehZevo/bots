# Bot detail modal

- Clicking/tapping a bot card opens that bot's detail as a modal over the Bots tab — Run now, Stop (while running, see `bots/interrupt.md`), Enable/Disable, Clear memory, Delete, role picker, triggers, and run history (see `dashboard.md`); the panel behind keeps showing the cards.
- The modal closes via its close button, Escape, or tapping outside; closing changes nothing about the bot.
- Tapping another card switches the modal to that bot in place; on phones the modal spans the full screen.
