# Navigation

- A persistent left sidebar on desktop carries the tabs — `Bots`, `Roles`, plus one per open bot view; the main area shows the selected tab.
- Below tablet width the sidebar is replaced by a hamburger button in the top bar; tapping it opens an overlay drawer holding the same tabs and form, which closes on selecting a tab or tapping outside it.
- The active tab is visually marked; selecting a bot card activates that bot's tab.
